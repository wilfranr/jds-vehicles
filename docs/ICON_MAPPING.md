# Mapeo de Iconos: Prototipo (Material Symbols) → Lucide React

En F0-03 se decidió adoptar `lucide-react` en lugar de cargar fuentes remotas de Google Fonts / Material Symbols.

A continuación se documenta el mapeo de los iconos utilizados en el prototipo (`docs/prototype/code.html`):

| Icono prototipo (Material Symbols) | Icono equivalente en `lucide-react` | Contexto de uso                       |
| :--------------------------------- | :---------------------------------- | :------------------------------------ |
| `search`                           | `Search`                            | Barra de búsqueda del header          |
| `admin_panel_settings`             | `Shield` o `UserCog`                | Acceso a panel de administración      |
| `notifications`                    | `Bell`                              | Alertas / notificaciones del usuario  |
| `manage_search`                    | `Search` / `Sparkles`               | Barra de búsqueda hero de inventario  |
| `tune`                             | `SlidersHorizontal`                 | Botón "Explorar Inventario" y filtros |
| `directions_car`                   | `Car`                               | Tipo de carrocería / vehículo         |
| `speed`                            | `Gauge`                             | Kilometraje / velocímetro             |
| `local_gas_station`                | `Fuel`                              | Tipo de combustible                   |
| `settings`                         | `Cog`                               | Transmisión                           |
| `calendar_month`                   | `Calendar`                          | Año de fabricación / cita             |
| `location_on`                      | `MapPin`                            | Ubicación del concesionario           |
| `phone`                            | `Phone`                             | Teléfono de contacto                  |
| `share`                            | `Share2`                            | Compartir ficha técnica               |
| `favorite`                         | `Heart`                             | Guardar en favoritos                  |
| `check_circle`                     | `CheckCircle2`                      | Puntos periciales peritados / checks  |
| `bolt`                             | `Zap`                               | Vehículos eléctricos / híbridos       |
| `chat`                             | `MessageSquare`                     | Mensaje o consulta rápida             |
| `close`                            | `X`                                 | Cerrar modales o chips de filtro      |
| `arrow_forward` / `chevron_right`  | `ChevronRight` / `ArrowRight`       | Navegación y enlaces                  |
| `filter_list`                      | `Filter`                            | Filtro móvil                          |
