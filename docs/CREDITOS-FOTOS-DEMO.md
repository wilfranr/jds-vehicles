# Créditos de las fotos de demostración

Las 60 fotos del catálogo de demostración (20 vehículos, 3 por vehículo) provienen de [Wikimedia Commons](https://commons.wikimedia.org/) con licencias abiertas (CC BY, CC BY-SA, CC0 o dominio público). Las licencias CC BY y CC BY-SA exigen **atribución**; las imágenes se recodificaron a WebP y se redimensionaron.

**Son solo para la demostración.** Antes del lanzamiento deben sustituirse por fotos propias de cada unidad (los vehículos reales del concesionario), y este archivo ya no será necesario.

Los datos de los vehículos (precios, kilometrajes, placas, colores, descripciones) son **ficticios** y solo ilustran el catálogo.
